AI 网页翻译助手 v2.0  使用说明
================================================================

一句话：平时用免费整页双语翻译；遇到术语不准、长句读不通、
AI/金融/社媒内容翻得别扭时，点一下「AI 精译」，
用你自己已有的 API 订阅重翻。术语库免费和 AI 都遵守。

----------------------------------------------------------------
一、安装（Edge 137 及以上必须手动加载一次）
----------------------------------------------------------------
Edge 137 以后，官方停用了命令行 --load-extension 自动加载，
所以「一键安装.bat」现在做的是安装引导，不再强行改浏览器。

1. 把整个文件夹放在固定位置，例如：
   D:\AI网页翻译助手
   装好后不要移动、不要改名。未打包扩展的 ID 和路径有关，
   移动后扩展会被当成新扩展，原来的设置和术语库会读不到。

2. 双击「一键安装.bat」。
   它会：
   - 打开 extension 文件夹
   - 把 extension 的完整路径复制到剪贴板
   - 打开 edge://extensions

3. 在 edge://extensions 页面：
   - 打开「开发人员模式」
   - 点「加载解压缩的扩展」
   - 在地址栏粘贴路径，回车
   - 选择 extension 文件夹（能看到 manifest.json 的那一层）

4. 在 Edge 工具栏的扩展菜单里，把「AI 网页翻译助手」固定出来。

5. 刷新已经打开的网页。扩展更新后也要刷新一次，
   否则旧标签页里跑的还是旧脚本。
   如果替换了 extension 里的文件，必须先到 edge://extensions
   点一下本扩展的「重新加载」，再刷新网页；只刷新网页不够，
   后台 Service Worker 还会是旧的。否则会出现
   「扩展配置读取失败」或免费翻译失败。

如果不想用 bat，也可以手动打开 edge://extensions，
按上面第 3、4 步操作。

----------------------------------------------------------------
二、第一次设置（3 分钟）
----------------------------------------------------------------
1. 点工具栏「译」图标 →「翻译此页」，先用免费通道试一段英文。
   免费通道：腾讯交互翻译优先，失败时自动尝试微软 / 谷歌 / MyMemory。

2. 想要更准：点弹窗右上角齿轮 →「AI 引擎」
   - 默认已经选中 OpenCode Go / GLM-5.3-Flash
   - 点「从 OpenCode 导入 Key」
   - 选这个文件：
     C:\Users\你的用户名\.local\share\opencode\auth.json
     （找不到就双击「打开OpenCode配置文件夹.bat」，它会定位 auth.json 并复制路径，
       在文件选择框里 Ctrl+V 粘贴路径回车即可）
   - 点「测试连接」
   没有 Key 也完全可以一直用免费通道。
   也可以手动换成 DeepSeek、智谱、通义、Kimi、OpenAI、
   Gemini、Claude 等服务商，或填自定义 OpenAI 兼容接口。

3. 打开「术语库」，里面已经预置：
   - 你原来整理的 AI 术语（保留英文）
   - 补充的 AI / 金融 / 社媒 / 素材常用词
   可以直接改、停用、删除，也可以导入你自己的 CSV。

4. 建议把「打开网页自动翻译」保持关闭。
   平时手动点翻译，遇到常看的网站再在弹窗里勾「自动翻译本站」。

----------------------------------------------------------------
三、日常使用
----------------------------------------------------------------
【整页翻译】
点「译」图标 →「翻译此页」，或按 Alt+T。
外文段落下方插入中文译文，原文保留；再按一次 Alt+T 还原。

【AI 精译】
免费译文不够准、术语翻错、长句读不通时：
- 弹窗里的「AI 精译」
- 页面右上角悬浮球的「AI 精译」
- 快捷键 Alt+A
会用你配置的模型把整页重翻一遍。
划词气泡、输入框弹层里也有单独的「AI 精译」。

【划词翻译】
选中 2 个字符以上的外文，自动弹出气泡。
气泡里可以：复制、AI 精译、朗读、关闭。
也可以右键选中的文字，直接选「AI 精译选中文字」。
Esc 或点空白处关闭。

【悬停翻译】
在「通用设置」里打开后，按住 Alt 把鼠标停在段落上，
会在旁边显示译文，不打断阅读。

【输入框翻译】
在网页的输入框 / 多行文本框 / 可编辑区域里，
按 Ctrl+Shift+Enter，弹层显示译文，
可以「复制」或「替换原文」。替换后可用 Ctrl+Z 撤销。

【动态内容】
默认开启。社媒、素材站、单页应用滚动加载的新内容会自动补译。
如果页面结构特别复杂，刷新后重新翻译一次最稳。

【站点规则】
- 弹窗里的「自动翻译本站」：以后打开该站自动翻译。
- 设置 → 站点规则：可以加「始终自动」或「从不自动」。
  支持子域名，例如 news.example.com 会继承 example.com。
- 「从不自动」只阻止自动翻译，手动点按钮仍然会翻。

【快捷键】
Alt+T    翻译 / 还原当前页面
Alt+A    AI 精译当前页面
Alt+S    翻译选中的文字
Ctrl+Shift+Enter  翻译输入框内容
Esc      关闭气泡 / 弹层
可在 edge://extensions/shortcuts 修改。

【显示方式】
- 原文下方：默认，双语对照
- 原文上方
- 仅显示译文
表格、按钮等特殊结构在「仅显示译文」下会自动退回对照显示，
避免把网站布局撑坏。

【译文样式】
可以调颜色、字号、分隔线、深色页面自动适配。
只影响插入的译文，不改网站原文样式。

【跳过区域】
设置 → 通用设置 → 高级，可以填 CSS 选择器，
例如：nav, footer, .ad-banner
适合金融看板、后台系统，避免翻译菜单和广告。

----------------------------------------------------------------
四、术语库怎么用
----------------------------------------------------------------
两种策略：
1）保留英文原文
   例如 Agent、Token、MCP、GPT-4、FOMC、ETF。
   免费翻译会先用占位符把它保护起来，翻完再还原，
   不会被谷歌/腾讯翻成「代理人」「令牌」「变压器」。

2）指定译法
   例如 Function Calling → 函数调用
   Hawkish → 鹰派
   Market cap → 市值
   免费翻译会强制替换成你写的词；AI 翻译会把这条写进提示词。

免费和 AI 的区别：
- 免费通道：术语替换成占位符 → 翻译 → 还原术语
- AI 通道：命中的术语作为「必须遵守」写进提示词，
  同时带上页面标题和域名，让模型按 AI / 金融 / 社媒语境选译法。

维护建议：
- 只收「翻错会很难受」的词：模型名、产品名、指标名、行业黑话。
- 普通词不要收太多，否则会干扰正常句子。
- 拿不准先停用，不要直接删。
- 选中网页上的词 → 右键「将选中文字加入术语库…」，
  会直接打开新增表单。

导入格式：
- CSV / TSV / JSON
- CSV 表头：原文,译法,策略,分类,备注
- 也支持每行「英文=中文」
- 策略可写：保留英文 / 指定译法 / keep / translate
- 导入时可选择「追加并更新重复项」或「替换现有术语库」

导出：
- 术语库页：导出 CSV / 导出 JSON
- 数据与备份：连同设置一起导出备份

----------------------------------------------------------------
五、AI 服务商
----------------------------------------------------------------
内置：
OpenCode Go、DeepSeek、智谱 GLM、阿里通义千问、月之暗面 Kimi、
硅基流动、OpenAI、Google Gemini、Anthropic Claude、
OpenRouter、本地 Ollama / LM Studio、自定义 OpenAI 兼容接口。

默认已经是 OpenCode Go + GLM-5.3-Flash（模型 ID：glm-5.3-flash）。
设置页 AI 引擎 →「从 OpenCode 导入 Key」→ 选
C:\Users\你的用户名\.local\share\opencode\auth.json
然后点「测试连接」即可。
也可以把模型改成 glm-5.3、deepseek-v4.1-flash 等 Go 里的其他模型。
提示：OpenCode Go 官方定位是 coding agent，若大量翻译请求遇到限流，
可以随时在设置里换成 DeepSeek / 智谱的直连接口。
各家的 Key 申请地址在设置页对应服务商下面有链接。

- API Key 只保存在本机扩展的 chrome.storage.local。
- 不会上传到任何中转服务器，扩展本身也没有服务器。
- 使用 OpenAI / Gemini / Claude 需要相应的网络条件。
- 本地 Ollama 如果报跨域，启动时设置环境变量：
  OLLAMA_ORIGINS=*
- 自定义接口只要兼容 /chat/completions 即可。

高级参数：
- 温度默认 0.2，越低术语越稳定。
- 每批段落数默认 12；报「输出被截断」时调到 8。
- 自动 AI 补译默认关闭。打开后，免费结果疑似没翻好时，
  会自动用 AI 重译那几段，会产生 API 费用。
- 自定义提示词留空即可，内置规则已经包含你原来的
  「保留 AI 术语、保护代码、按语境选译法」。

----------------------------------------------------------------
六、常见问题
----------------------------------------------------------------
Q：为什么有的页面不能翻译？
A：edge:// 内置页、扩展商店、PDF 阅读器不允许扩展注入脚本。
   普通 http/https 网页都可以。file:// 本地网页需要在
   edge://extensions 的扩展详情里打开「允许访问文件 URL」。

Q：点翻译没反应 / 旧标签页划词弹两次？
A：扩展安装或更新后，刷新页面。旧版 v1 的脚本会残留在
   未刷新的标签页里，刷新就没了。
   如果提示「扩展配置读取失败」或免费翻译失败，
   先去 edge://extensions 点本扩展的「重新加载」，
   再刷新网页。只刷新网页不会重启后台 Service Worker。

Q：免费通道失败？
A：腾讯通道国内直连最稳。微软、谷歌可能受网络影响。
   可以在「通用设置 → 免费通道」手动指定，或配置 AI 备用。
   免费接口有频率限制，翻大页面时偶尔失败，重试即可。

Q：AI 报 401 / 403 / 404 / 429？
A：401 Key 不对或过期；403 无权限/地区限制；
   404 接口地址或模型名不对；429 额度或频率限制。
   先在「AI 引擎」点「测试连接」，按错误提示检查。

Q：AI 输出被截断？
A：把「每批段落数」调小，例如 8 或 6。

Q：译文影响网站布局？
A：已经尽量保持原文版式：导航、按钮直接换成中文，
   正文译文放进原段落内部，行内译文不改变原行高。
   如果某个网站仍被撑开，可切换「仅显示译文」，
   或只用划词翻译，也可以在「跳过区域」里排除导航。

Q：翻译缓存怎么工作？网站更新后还会命中吗？
A：缓存按「每段文本」保存，不保存整页截图。
   下次打开或刷新时，没变的段落直接命中缓存，
   变了的段落才重新翻译；这样比整页重翻省，也比
   整页快照更不容易显示过期内容。
   修改术语库后，旧缓存会失效，这是为了让新术语生效。

Q：移动文件夹后设置没了？
A：未打包扩展的 ID 和路径绑定。移动后相当于新扩展，
   旧设置读不到。用「数据与备份 → 导出设置 JSON」备份，
   移动后重新导入。

Q：支持 PDF / 视频字幕 / 图片 OCR 吗？
A：暂不支持。当前版本专注网页正文、划词、悬停、
   输入框和动态内容。后续可以按需要加。

Q：Edge 更新后扩展消失了？
A：重新打开 edge://extensions，加载解压缩的 extension 文件夹。
   只要路径没变，设置和术语库都还在。

----------------------------------------------------------------
七、隐私
----------------------------------------------------------------
- 免费翻译会把待翻译文本发送到腾讯 / 微软 / 谷歌 / MyMemory 的公共翻译接口。
- AI 精译会把文本发送到你配置的 AI 服务商。
- API Key、设置、术语库、翻译缓存只存在本机扩展存储。
- 扩展没有自建服务器，不收集浏览记录。
- 涉及未公开财务数据、内部文档时，建议关闭自动翻译，
  或只使用你信任的 AI 接口。

八、文件说明
----------------------------------------------------------------
extension\                 扩展本体（加载这一层）
extension\manifest.json    扩展清单
extension\background.js    后台：免费/AI 路由、术语库、缓存
extension\content.js       网页内：整页/划词/悬停/输入框
extension\popup.html       点图标后的弹窗
extension\options.html     设置页（AI、术语库、站点规则、备份）
extension\lib\             术语库、免费引擎、AI 调用、默认术语
一键安装.bat               安装引导：打开扩展页 + 复制路径
打开OpenCode配置文件夹.bat  定位 auth.json，方便导入 OpenCode Go Key
创建桌面快捷方式.ps1        可选：在桌面放一个「扩展管理」快捷方式
使用说明.txt               本文件
deepseek_*.md / *.txt       你原来的术语整理，已并入默认术语库
